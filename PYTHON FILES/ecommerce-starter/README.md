# E-commerce Starter

A beginner-friendly e-commerce demo using Flask and vanilla JavaScript.

## Run locally

```powershell
cd "c:\Users\ishme\Desktop\PYTHON FILES\ecommerce-starter"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Then open http://127.0.0.1:5000 in your browser.
